How Merge Sort Works

Merge Sort is a divide-and-conquer sorting algorithm. It repeatedly divides an array into smaller halves until each part contains only one element, then merges those parts back together in sorted order.

  1. 01Divide the array into two halves.
  2. 02Recursively divide both halves.
  3. 03Continue until each subarray contains one element.
  4. 04Compare elements from the left and right subarrays.
  5. 05Place the smaller element into the merged array.
  6. 06Continue until both subarrays are completely merged.
  7. 07Repeat until the entire array is sorted.
